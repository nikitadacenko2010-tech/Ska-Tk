# Ska-Tka — маркетплейс объявлений

Полноценный маркетплейс на Node.js + Express + Sequelize + SQLite.
Готов к запуску и кастомизации.

## Возможности

- Регистрация и авторизация (JWT, httpOnly cookie, bcrypt)
- Роли: пользователь / администратор
- Публикация объявлений только админом (владельцем)
- До 7 фото на объявление, галерея с листанием
- Поиск и фильтры: категория, цена, состояние
- Корзина и оформление заказа с валидацией
- Избранное (в базе)
- Личный кабинет: заказы, избранное, аватар
- Админ-панель: статистика, пользователи, блокировка, удаление товаров
- Аналитика: посещения, просмотры, входы, заказы, активные пользователи
- Защита: bcrypt, rate-limit на авторизацию, валидация на сервере

## Стек

Node.js · Express · Sequelize · SQLite · JWT · Multer · bcrypt
